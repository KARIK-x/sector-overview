# Visualization Roadmap

Implemented in this phase:

- Brand mark and wordmark.
- Reduced-motion-aware chart animation and accessible chart labels.
- Rolling relative-strength persistence chart on Sector Explorer.
- Cap-weighted sector contribution view on Dashboard, labelled as a snapshot estimate.

Deferred with reasons:

- Correlation clustering: requires a documented clustering rule and tests before changing the matrix order.
- Historical market-cap concentration trend: only a snapshot market cap is available; no historical series exists.
- Liquidity concentration trend: turnover history exists, but a verified concentration time series is not yet built.
- Breadth deterioration signal: needs a documented threshold and backtest before presentation as a signal.
